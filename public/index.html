HOW TO READ THE RESULTS

From sensor values to evidence

Total acceleration

The combined acceleration vector. It may include gravity, so a phone resting still can show a value close to 9.81 m/s².

Linear acceleration

Acceleration with gravity removed by the device/browser. It is a more useful indicator of movement intensity, when available.

Rotation speed

The combined angular velocity. It describes how quickly the phone turns, not its final orientation angle.
